# New Eden Career Constellation

Single-page HTML5 3D activity map built from the supplied **New Eden Activities & Careers — Edition 2026.08** PDF package.

## Open

Open `dist/index.html` in a browser. It is self-contained and does not need a local server.

## Contents

- `dist/index.html` - interactive one-page career constellation
- `New-Eden-Career-Constellation-HTML5.zip` - packaged share copy
- `source/` - extracted PDFs, source text, README, and checksums from the supplied archive
