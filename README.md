# New Eden Career Atlas

Self-contained, readable HTML5 atlas built from the supplied **New Eden Activities & Careers — Edition 2026.08** PDF package.

## Open

Open `dist/index.html` in a browser. It has no external runtime dependencies and does not require a local server.

## What it includes

- 25 career and activity paths grouped into five scan-friendly category lanes
- At-a-glance entry difficulty, risk, cost, Omega access, and progression depth
- Search plus category, difficulty, risk, cost, and access filters
- Responsive activity details and source references
- Keyboard navigation, reduced-motion support, and print styling

## Contents

- `dist/index.html` — interactive one-page career atlas
- `source/` — extracted PDFs, source text, README, and checksums from the supplied archive
